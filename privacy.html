ツイタテ

プライバシーポリシー

最終更新日：2026年11月17日

ツイタテ（以下「本アプリ」）は、iPhone・iPad の中だけで広告の読み込みを止めるアプリです。本アプリは、あなたの個人情報や利用状況を集めません。

集める情報

本アプリの開発者は、あなたに関する情報を一切集めません。開発者が運営するサーバーはなく、分析やクラッシュの情報を送る仕組みも入れていません。

端末の中にだけ保存する情報

次の情報は、あなたの端末の中にだけ保存され、開発者には送られません。アプリを削除すると消えます。

  • 止めた広告の数（日ごと）と、止めたサイトの名前の履歴
  • 許可リスト・拒否リストなど、あなたが登録したルール
  • 設定と、ツイタテ プラスを購入したかどうか

VPN の使い方

本アプリは、iOS の VPN の仕組みを、端末の中で動く DNS のフィルタとしてだけ使います。

  • トンネルに入るのは、名前の問い合わせ（DNS）と、あなたが拒否リストに登録した IP アドレス宛ての通信だけです。それ以外の通信は、ふだんどおり直接インターネットに出ていきます。
  • 本アプリは、閲覧したページの内容や通信の中身を読みません。

外部に送られる情報

本アプリが動くために、次の通信が発生します。いずれも開発者には届きません。

  • DNS の問い合わせ： 広告でないサイトの名前の問い合わせは、設定で選んだ DNS 事業者（初期設定は Cloudflare。ほかに Google、Quad9）にそのまま転送されます。各社の扱いは、各社のプライバシーポリシーに従います。
  • ブロックリストの取得： リストの更新のとき、AdGuard のフィルタの配布元と GitHub からリストを読み込みます。
  • 購入： ツイタテ プラスの購入と復元は、Apple の仕組み（App Store）で行います。開発者は、あなたの支払い情報を受け取りません。

Safari 拡張

Safari 拡張は、広告の要素を隠すために、表示しているページの中で動きます。ページの内容を読み取って送ることはありません。

データの販売・利用・提供

本アプリの開発者は、あなたのデータを販売しません。いかなる目的でも利用せず、第三者に開示・提供しません。

子どものプライバシー

本アプリは年齢を問わず使えます。子どもを含めて、誰の情報も集めません。

変更

このポリシーを変えるときは、このページを更新し、最終更新日を改めます。

連絡先

本ポリシーについてのお問い合わせは、GitHub の Issues で受け付けています。
